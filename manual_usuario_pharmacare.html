Manual de usuario

Cómo usar PharmaCare

Guía completa para administradores, farmacéuticos y cajeros: aprende a manejar cada módulo del sistema paso a paso.

Versión del manual: 1.0 Sistema: PharmaCare Desarrollado por: HSWare Software

Introducción

PharmaCare es el sistema de gestión para farmacias que centraliza el control de inventario, ventas, proveedores, usuarios y reportes en un solo lugar. Este manual explica, paso a paso, cómo usar cada pantalla del sistema según el rol que tenga tu usuario.

Recomendamos leer primero la sección Roles y accesos para saber exactamente qué módulos vas a ver al iniciar sesión, ya que el menú se adapta automáticamente según tu perfil.

Roles y accesos

El sistema tiene 4 tipos de usuario. El menú lateral de la izquierda muestra únicamente los módulos permitidos para el rol con el que iniciaste sesión.

RolDescripciónMódulos visibles
Administrador Control total del sistema, incluida la gestión de usuarios. Dashboard, Productos, Ventas, Nueva Venta, Proveedores, Usuarios, Reportes
Farmacéutico Operación diaria completa, sin gestión de usuarios. Dashboard, Productos, Ventas, Nueva Venta, Proveedores, Reportes
Cajero Enfocado exclusivamente en el punto de venta. Dashboard, Productos, Ventas, Nueva Venta
Comercial Rol de demostración: solo puede consultar el manual interactivo del sistema (dentro de la app, menú Manual), sin acceso a datos reales. Manual interactivo
Si intentas entrar a una pantalla que tu rol no tiene permitida, el sistema te redirige automáticamente al Dashboard (o al Manual, en el caso del rol Comercial).

Iniciar sesión

Todos los roles
  1. Abre PharmaCare en el navegador. Verás la pantalla de inicio de sesión.
  2. Ingresa tu correo electrónico y contraseña asignados por el administrador.
  3. Presiona Iniciar sesión. Si los datos son correctos, entrarás directamente al Dashboard (o al Manual, si tu rol es Comercial).
Si olvidaste tu contraseña, solicita a un Administrador que la restablezca desde el módulo de Usuarios.

Panel principal (Dashboard)

AdministradorFarmacéuticoCajero

Es la primera pantalla que ves al iniciar sesión. Muestra un resumen general del estado de la farmacia y accesos directos a las tareas más frecuentes.

  1. Revisa las tarjetas de resumen en la parte superior para ver el estado general del negocio.
  2. Usa la sección Accesos Rápidos para saltar directo a Nueva Venta, Productos u otros módulos.
  3. Presiona el botón de actualizar (ícono circular) si necesitas refrescar los datos sin recargar la página.

Productos e inventario

AdministradorFarmacéuticoCajero

Aquí se administra el catálogo completo de medicamentos y productos de la farmacia, junto con su stock disponible.

Buscar un producto

  1. Escribe en el campo «Buscar por nombre, código de barras...» y los resultados se filtran automáticamente.
  2. Presiona Buscar si necesitas forzar la búsqueda.

Registrar un nuevo producto

  1. Presiona el botón Nuevo Producto en la parte superior derecha.
  2. Completa el formulario con los siguientes datos:
Nombre *Nombre comercial del producto
Código de barrasCódigo para escaneo rápido
Categoría *Tipo de producto
ProveedorProveedor asociado
Precio *Precio de venta al público
Costo *Costo de adquisición
Stock *Cantidad disponible actual
Stock mínimo *Nivel para alerta de reposición
Fecha de expiraciónVencimiento del lote
DescripciónNotas adicionales del producto
  1. Presiona Guardar para crear el producto, o Cancelar para descartar los cambios.

Editar o eliminar un producto

  1. Ubica el producto en la tabla y presiona el ícono de lápiz (Editar) para modificar sus datos.
  2. Presiona el ícono de papelera (Eliminar) para darlo de baja. Esta acción no se puede deshacer.
Define siempre el Stock mínimo: es la base para futuras alertas de reposición y evita quiebres de inventario.

Historial de ventas

AdministradorFarmacéuticoCajero

Consulta todas las ventas registradas en el sistema, con filtros por fecha.

  1. Usa los campos Fecha inicio y Fecha fin para acotar el periodo que quieres revisar.
  2. Presiona Filtrar/Actualizar (ícono circular) para aplicar los cambios.
  3. Presiona Nueva Venta en la parte superior para ir directo al punto de venta.

Nueva venta (Punto de venta)

AdministradorFarmacéuticoCajero

Es la pantalla para registrar una venta en el momento, pensada para uso rápido en caja.

  1. Escribe en el buscador «Nombre o código de barras...» para localizar el producto.
  2. Presiona sobre el producto (o el botón +) para agregarlo al carrito.
  3. En el carrito, ajusta cantidades o quita productos con el ícono correspondiente.
  4. Completa, si aplica, los datos del cliente: nombre y número de teléfono.
  5. Verifica el total calculado automáticamente en la parte inferior.
  6. Presiona Finalizar Venta para confirmar y generar el comprobante.
Revisa siempre el carrito antes de finalizar: una vez confirmada, la venta descuenta el stock automáticamente.

Proveedores

AdministradorFarmacéuticoCajero

Administra el directorio de proveedores que abastecen a la farmacia.

  1. Presiona Nuevo Proveedor para registrar uno nuevo.
  2. Completa el formulario:
NombreNombre del proveedor
Persona de contactoContacto directo
CorreoCorreo de contacto
TeléfonoNúmero de contacto
RFCIdentificación fiscal
DirecciónCalle, ciudad, estado, C.P. y país
NotasInformación adicional
  1. Presiona Guardar. Para modificar un proveedor existente usa el ícono de lápiz; para eliminarlo, el ícono de papelera.

Usuarios del sistema

AdministradorFarmacéuticoCajero

Módulo exclusivo del Administrador para crear y gestionar las cuentas de acceso al sistema.

  1. Presiona Nuevo Usuario.
  2. Completa nombre completo, correo electrónico, contraseña, teléfono y selecciona el rol (Administrador, Farmacéutico o Cajero).
  3. Presiona Guardar para crear la cuenta.
  4. Usa el ícono de lápiz para editar los datos o el rol de un usuario existente, y el de papelera para eliminarlo.
Asigna el rol correcto a cada usuario: define qué módulos podrá ver en el menú lateral.

Reportes

AdministradorFarmacéuticoCajero

Panel con información analítica del negocio, dividido en tres bloques:

  • Resumen de inventario: estado general del stock disponible.
  • Productos por categoría: distribución del catálogo.
  • Top 10 productos más vendidos: ranking de productos con mayor rotación.
  1. Presiona el botón de actualizar para refrescar la información con los datos más recientes.

Consultas

AdministradorFarmacéuticoCajero
Este acceso ya aparece en el menú lateral, pero la pantalla de Consultas farmacéuticas se encuentra en desarrollo. Estará disponible en una próxima actualización del sistema.

Cerrar sesión

Todos los roles
  1. En la parte inferior del menú lateral, presiona Cerrar Sesión.
  2. El sistema te regresará automáticamente a la pantalla de inicio de sesión.

Consejos y buenas prácticas

  • Registra el stock mínimo de cada producto para evitar quiebres de inventario.
  • Verifica la fecha de expiración al dar de alta un producto para llevar control de vencimientos.
  • Revisa el Historial de ventas con filtro de fechas al cierre de cada turno.
  • Solo el Administrador debe crear cuentas de usuario; asigna el rol correcto a cada persona.
  • Usa Reportes periódicamente para tomar decisiones de compra y reposición.

Preguntas frecuentes

¿Por qué no veo el módulo de Usuarios?

Solo el rol Administrador tiene acceso a la gestión de usuarios. Si necesitas crear o editar cuentas, solicítalo a un administrador.

¿Qué pasa si me equivoco al registrar una venta?

Contacta a un Administrador o Farmacéutico para revisar el caso; actualmente las ventas confirmadas no se editan desde la pantalla de historial.

¿Por qué el rol Comercial solo ve el manual?

Es un acceso de demostración pensado para mostrar el funcionamiento del sistema sin exponer datos reales de la farmacia.
